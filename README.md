🛡️ Cybersecurity Awareness Portal

A simple and interactive Cybersecurity Awareness Portal designed to help beginners learn essential cybersecurity concepts, recognize common online threats, and develop safer digital habits.

The project is built using HTML, CSS, and JavaScript and runs completely in the browser without requiring a backend or database.

📌 Project Overview

Cybersecurity is an important part of everyday digital life. Many security incidents happen because users are unaware of common threats or unsafe online practices.

This project provides an easy-to-use learning platform where users can explore cybersecurity topics, test their knowledge through quizzes, practice with flashcards, and access useful security resources.

✨ Features
🏠 Home Page – Introduction to cybersecurity awareness
📚 Learn Section – Learn important cybersecurity concepts and safety practices
🃏 Interactive Flashcards – Review cybersecurity concepts interactively
🧠 Quick Quiz – Test cybersecurity knowledge with an interactive quiz
🔗 Security Resources – Access useful cybersecurity resources
🌙 Dark / Light Theme – Switch between different visual themes
🔤 Text Size Controls – Improve readability with text-size options
📱 Responsive Design – Designed to work across different screen sizes
🍔 Mobile Navigation – Mobile-friendly navigation menu
💻 No Backend Required – Runs entirely on the client side

🚀 How to Run
Option 1 — Open Directly
Download or clone the repository.
Open the project folder.
Double-click index.html.
The website will open in your browser.
Option 2 — Using VS Code
Clone the repository:
git clone https://github.com/Shreyas-Bhavsar/Cybersecurity-Awareness-portal.git
Open the project in VS Code:
cd Cybersecurity-Awareness-portal
code .
Open index.html using a browser or the Live Server extension.
